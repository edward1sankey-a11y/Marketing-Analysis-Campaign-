# Marketing Campaign Analysis 

## Overview
This is my first Python Project.

This project uses Python to analyse the performance of four hypothetical marketing campaigns.

The project was created as a beginner Python and marketing analytics project.

## Tools Used

- Python
- Pandas
- Matplotlib

## Analysis

The analysis looks at:

- Advertising spend
- Clicks
- Conversions
- Impressions
- Revenue
- Conversion rate
- Click-through rate (CTR)
- Cost per conversion
- Return on Ad Spend (ROAS)

## Visualisations

The project includes charts comparing:

- ROAS by campaign
- Revenue by campaign

## Key Findings

The analysis identifies which campaign has the lowest cost per conversion and compares campaign performance using ROAS and revenue.

## Data

The dataset is synthetic and was created for learning purposes. It does not in any way represent real company campaign data.
